# Trabalho no BIQMapa

- Faça correções e recursos em uma branch própria. Não envie alterações diretamente à `main`.
- Abra um pull request com o que mudou, os testes realizados e o instalador de teste quando houver mudança no aplicativo.
- Só integre à `main` depois de Lucas (`lucaspfvr`) comentar **APROVADO** no PR ou escrever **APROVADO** na conversa, identificando a revisão correspondente.
- A aprovação vale para a revisão apresentada. Se houver alteração relevante depois dela, peça uma nova aprovação.
- Nunca publique relatórios de imóveis, JSON de contribuintes, CPF/CNPJ, fotos reais, bancos ou backups. Os testes usam dados fictícios.
- Preserve a base local nas atualizações. Não altere a referência geográfica de desenhos existentes.
- Use textos diretos em português no README, nos commits e na interface.
